# DeskFlow

DeskFlow is an IT helpdesk and asset management app for small offices.

I got this idea from my work as an IT Executive. In offices, employees often report IT problems through WhatsApp or calls. It can be difficult to manage all the problems and company devices.

So I made DeskFlow to keep tickets and company assets in one place.

## Features

- Employee and Admin login
- Create IT tickets
- Check ticket status
- Add comments
- Manage company assets
- Assign assets to employees
- Check warranty details
- Admin dashboard
- Real-time updates
- Mobile responsive

## Tech Used

- React JS
- Firebase Authentication
- Firestore
- React Router
- CSS
- Vercel

## How to Run Locally

1. Clone the repo

```
git clone https://github.com/VinayYadav07/deskflow-it-helpdesk.git
```

2. Go to the project folder

```
cd deskflow-it-helpdesk
```

3. Install packages

```
npm install
```

4. Add your own Firebase project details in `src/firebase.js`

5. Start the app

```
npm run dev
```

6. Open http://localhost:5173 in the browser
